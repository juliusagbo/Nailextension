🗄️ DATABASE STRUCTURE (10 Tables)
==================================

MAIN BUSINESS TABLES (7):
-------------------------

1. USERS (🔵 Blue)
   ├─ id (PK)
   ├─ email (UK)
   ├─ name, password, role
   ├─ phone, address, status
   └─ profile_picture, notes
   └─ Relationships: 1→N appointments, favorites, activity_logs, sessions
                   1→1 password_reset_tokens

2. SERVICES (🟣 Purple)
   ├─ id (PK)
   ├─ name, description, price
   ├─ duration_minutes, category
   ├─ location_type, status
   └─ image_url
   └─ Relationships: 1→N appointments, favorites

3. APPOINTMENTS (🟢 Green)
   ├─ id (PK)
   ├─ user_id (FK→users)
   ├─ service_id (FK→services)
   ├─ appointment_date, location_type
   ├─ customer_address, amount
   ├─ status, payment_status
   └─ notes
   └─ Relationships: N→1 users, services

4. FAVORITES (🟠 Orange)
   ├─ id (PK)
   ├─ user_id (FK→users)
   ├─ service_id (FK→services)
   └─ Unique constraint: (user_id, service_id)
   └─ Relationships: N→1 users, services

5. GALLERIES (🩷 Pink)
   ├─ id (PK)
   ├─ title, description
   ├─ image_path, alt_text
   ├─ category, is_featured
   ├─ sort_order, is_active
   └─ (Standalone table)

6. ACTIVITY_LOGS (🟢 Green)
   ├─ id (PK)
   ├─ user_id (FK→users, nullable)
   ├─ user_type, user_name, user_role
   ├─ action, details
   ├─ ip_address, user_agent
   ├─ model_type, model_id
   ├─ old_values (JSON), new_values (JSON)
   └─ Relationships: N→1 users (optional)

7. SETTINGS (🟡 Yellow)
   ├─ id (PK)
   ├─ key (UK)
   ├─ value, type, description
   └─ (Standalone table)

SYSTEM TABLES (3):
------------------

8. CACHE (🔵 Light Blue)
   ├─ key (PK)
   ├─ value, expiration

9. JOBS (🔵 Light Blue)
   ├─ id (PK)
   ├─ queue, payload, attempts
   ├─ reserved_at, available_at, created_at

10. PASSWORD_RESET_TOKENS (🔵 Light Blue)
    ├─ email (PK)
    ├─ token, created_at
    └─ Relationships: 1→1 users (email)

11. SESSIONS (🔵 Light Blue)
    ├─ id (PK)
    ├─ user_id (FK→users, nullable)
    ├─ payload, last_activity
    └─ Relationships: N→1 users (optional)
